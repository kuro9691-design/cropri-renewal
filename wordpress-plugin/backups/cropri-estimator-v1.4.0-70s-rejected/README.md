# CROPRI Estimator

お客様が操作する見積もり画面(シルク／DTG／DTF・価格曲線付き)。

- ショートコード: `[cropri_estimator]`
- 5001商品詳細ページ: `[cropri_5001_product]`
- シルクは freee 見積書と同じ明細(税別)を表示。計算は社内の見積明細ルール（cropri_quote.py）と同じ。
- 「見積もりを依頼する」で送られた内容は、管理画面の「見積もり依頼」に**非公開**で保存し、kurokui@cropri.com にだけ届く(宛先は cropri-estimator.php の CROPRI_ESTIMATOR_MAIL_TO)。お客様情報はサイト上に公開しない。
- 価格を変えるときは `assets/estimator.js` の `SALE`(と版代 `LINE.plate`)を直し、`cropri_quote.py` も同じ値に直す。
- 原価・利益・仕入先の情報は入れない。
- 5001の通常シリーズは `5001-01` アダルト、`5001-02` キッズ、`5001-03` ガールズを登録。価格はすべて税込。
