# CROPRI Customer Quote(仮の見積ページ)

本番の見積もり画面(cropriの「cropri 5001 見積もり」、シルク／DTG／DTF・価格曲線付き)に向けた仮の見積ページです。

- **ログイン中の管理者にだけ表示**し、それ以外の人には何も出力しません(CSSも出しません)。
- 価格はラブラボ水準の販売価格(税込)。原価・利益・仕入先は書きません。
- **お客様の名前・案件名・連絡先などの個人情報は書きません。**

## 設置

1. `cropri-customer-quote.zip` を管理画面の「プラグイン → 新規追加 → プラグインのアップロード」から入れて有効化します。
2. 非公開(または下書き)のページにショートコードブロックで `[cropri_customer_quote]` を置きます。

## 金額更新

`cropri_customer_quote_lines()` の明細だけを直します。価格の正本は `G:\マイドライブ\cropri\PROGRESS.md` の「見積もりの計算」(ラブラボ水準)です。
