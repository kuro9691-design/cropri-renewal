# CROPRI Product Gallery

商品詳細ページのための共通ギャラリー／Lightboxプラグインです。外部ライブラリは使わず、ショートコードが置かれたページだけにCSSとJavaScriptを読み込みます。

## Elementorでの使い方

1. WordPressメディアライブラリで使う画像を登録し、添付IDを控える。
2. Elementorの「ショートコード」ウィジェットへ、次を入力する。

```
[cropri_product_gallery ids="101,102,103,104" labels="ブラック 正面,ブラック 背面,ホワイト 正面,着用イメージ"]
```

- `ids`: CROPRIメディアライブラリに登録済みの画像IDをカンマ区切りで指定します。
- `labels`: サムネイルの操作ラベルを同じ順番で指定します（任意）。
- `target`: 既存のElementor画像をメイン画像として使う場合に、その画像ウィジェットのCSS IDを指定します。例: `target="#cp5001-main-media"`。この指定時はメイン画像を重複出力せず、サムネイルと拡大ボタンだけを配置します。
- 画像は会員向け「販促素材ダウンロード」でWeb利用が許諾されたものを、CROPRIメディアへ登録して指定します。外部の公開商品ページや外部URLを使いません。

## 操作

- サムネイルのホバー／フォーカス／クリックでメイン画像をフェード切替
- メイン画像または「画像を拡大して見る」でLightbox表示
- 閉じるボタン、背景クリック、Escで閉じる
- 商品選択UIからの写真切替イベント `cropri:select-image` に対応します。選択色の写真がWordPressメディアにある場合、サムネイルにない画像も主画像とLightboxに表示できます。
