# CROPRI Estimator

お客様が操作する見積もり画面(シルク／DTG／DTF・価格曲線付き)。

- ショートコード: `[cropri_estimator]`
- 商品詳細下部のプリント概算: `[cropri_compact_estimator estimate_url="/estimate/"]`。`<div id="print-quote" class="cp5001-quote-shell">` 内などへ独立配置します。同じページに `[cropri_estimator]` を併設しないでください（既存見積のHTML IDを非表示で再利用するため）。
  - 5001-01の選択中の色・サイズを引き継ぎ、シルク1か所・1〜5色・数量1〜149枚の概算をその場で表示します。価格は既存の `[cropri_estimator]` を非表示で実行した結果を使い、別の計算式は持ちません。150〜499枚は条件を引き継いで詳細見積へ進みます。500枚以上は個別相談です。
  - 詳細見積の `print_pos` は `front/back/rsleeve/lsleeve`、`ink_colors` は1〜5のみ受信します。商品色・サイズ・数量は既存の許可リスト付き受信処理を使用し、問い合わせ送信は詳細見積ページでお客様が明示的に行います。
- 5001商品詳細ページ: `[cropri_5001_product]`
- 商品選択UI（Elementorの右カラムなどに独立配置）: `[cropri_product_selector gallery=".cropri-product-gallery" color_images="0001:2195,0002:2193"]`
  - `gallery` は同じページの既存 `[cropri_product_gallery]` のCSSセレクタ。省略すると写真は切り替わりません。
  - `color_images` は「色番号:WordPressメディア添付ID」のカンマ区切りです。指定色の主画像・拡大画像にCROPRIメディアを使います。指定しない色も、プラグイン同梱の許諾済み実物写真へ切り替わります。
  - `estimate_url` は見積ページ（既定 `/estimate/`）、`size_url` はサイズ表の完全なリンク（既定は現在ページの `#cp5001-size`）、`title` は商品名を指定できます。
  - 5001-01のCSVから抽出した61色を用意し、PCは全61色を常時表示、幅767px以下は初期8色（4列×2行）からボタンで61色へ展開・再び8色へ閉じます。各色のTシャツ正面写真・名前・番号、選択状態を示します。閉じても選択中の色・見積条件は保持します。画像は会員向け販促素材の元写真から機械縮小したCROPRIローカル配信素材で、生成手順は `scripts/build-5001-images.py` です。
  - 無地1枚の価格は色・サイズに応じて880～1,463円（税込）へ変わります。見積CTAは `sku` / `color` / `color_code` / `size` / `qty` を渡し、見積画面は色番号と名称が許可リストに一致するときだけ受け取ります。
  - 色写真を押すと、その色のS～XXXLのサイズ別在庫をポップアップで確認できます。CSV作成日時と週次更新・現在庫を保証しない旨を表示します。サイズ・枚数は見積CTAへ反映されます。
  - 在庫を更新するときは、会員向けCSVを `data/united-athle-stock/stock_all_latest.csv` へ差し替え、`python scripts/build-5001-stock.py` を実行してからZIPを作り直します。公開JSONには5001-01の色番号・6サイズ在庫数・CSV作成日時のみが入ります。重複行や欠落があれば生成を止めます。
- シルクは freee 見積書と同じ明細(税別)を表示。計算は社内の見積明細ルール（cropri_quote.py）と同じ。
- 「見積もりを依頼する」で送られた内容は、管理画面の「見積もり依頼」に**非公開**で保存し、kurokui@cropri.com にだけ届く(宛先は cropri-estimator.php の CROPRI_ESTIMATOR_MAIL_TO)。お客様情報はサイト上に公開しない。
- 価格を変えるときは `assets/estimator.js` の `SALE`(と版代 `LINE.plate`)を直し、`cropri_quote.py` も同じ値に直す。
- 原価・利益・仕入先の情報は入れない。
- 5001の通常シリーズは `5001-01` アダルト、`5001-02` キッズ、`5001-03` ガールズを登録。価格はすべて税込。
