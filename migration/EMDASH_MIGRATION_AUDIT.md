# WordPress → EmDash 移行監査

実施日: 2026-10-24  
対象: cropri.com  
実施環境: ローカルEmDash。本番WordPressは書き出しのみで、更新・公開・DNS変更は行っていない。

## 結論

WordPressの「記事データ」はEmDashへ一括移行できる。ただしElementor/FlatsomeのレイアウトとWordPress shortcodeは機能としては移らない。そのため、100ページを1件ずつ手作業で複製するのではなく、「本文・画像・URLは一括取込」と「共通Astroテンプレートへ置換」を組み合わせる。

## 取込結果

- WordPress WXR: `migration/wordpress/cropri.WordPress.2026-10-24.xml`
- 固定ページ: 36件取込、エラー0件
- 公開中として表示できた固定ページ: 10件
- 投稿: 17件（今回は未取込）
- メディア: 404件（今回は元URL参照のまま）
- その他: Elementorテンプレート6件、Forminatorフォーム5件、見積依頼3件、TablePress 3件

## 見つかった移行課題

1. WordPressの日本語slugがパーセントエンコード文字列のまま保存される。ローカルで旧slug照合フォールバックを追加し、代表ページの200応答を確認済み。本移行時はslug正規化とリダイレクト表を作る。
2. 現状のEmDashの有効localeは `en`。今回のページ表示には影響しないが、投稿・カテゴリ全件移行前に `ja` を有効化する。
3. 画像は現在cropri.comを外部参照。カットオーバー前に404件をEmDash側へコピーし、参照切れを防ぐ。
4. Elementor/Flatsome/Forminator/MW WP FormのshortcodeはAstroコンポーネントへ置換する。

## 推奨手順

1. `ja` localeと新slug方針を固定。
2. 「通常ページ」「商品一覧」「商品詳細」「手順」「フォーム」の共通テンプレートを作る。
3. 5001、見積もり、問い合わせを新テンプレートに接続。
4. 投稿17件とメディア404件をステージングへ取込。
5. URL対応表、SEO、フォーム通知を検査してから本番切替。
