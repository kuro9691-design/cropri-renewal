# CROPRI 制作ノウハウ記録・自動タグ付け・類似事例検索

## 目的

CROPRIの制作工程を、次の案件で再利用できる知識として残す。Notionは予定・状態・次の行動を管理し、GitHubは工程、判断理由、印刷条件、再現手順、関連コードの履歴を管理する。

## 1案件ごとに記録する項目

- 案件名と成果物
- 制作の時系列
- 各工程の担当者（本人・AI・外注先）
- 入稿前の原稿状態
- 加工内容と使用ツール
- 印刷方式、実寸、線幅、色数などの条件
- その判断を選んだ理由
- 受け渡したデータ形式と保存場所
- 最終成果物と品質確認結果
- 次回に再利用できる手順、失敗、注意点

信用情報、口座・カード情報、パスワード、APIキー、認証Cookieは記録しない。

## 初期タグ体系

| 分類 | 初期タグ |
|---|---|
| 商品 | Tシャツ、湯呑み、手ぬぐい |
| 原稿 | 鉛筆画、写真、デジタルイラスト |
| 加工 | ペン画変換、線幅調整、トレース |
| 印刷 | DTF、シルクスクリーン、陶器印刷 |
| 工程 | 下絵、AI加工、印刷データ作成、最終仕上げ |

タグはAIが候補を付け、人が必要に応じて修正する。表記揺れは既存タグへ寄せ、新しい工程や印刷方式だけを追加候補にする。

## 類似事例検索

新しい案件では、商品、原稿、加工、印刷、工程の一致数に加え、実寸・線幅・色数・素材の近さを使って候補を絞る。検索結果には、似ている理由、再利用できる工程、流用できない条件、確認が必要な差分を添える。

## 最初の試験事例

チェリ君の下絵をAIと協力してペン画へ調整し、湯呑みの印刷サイズと線幅条件に適合させ、最終的にチェリ君がパスで仕上げた工程を最初の記録例にする。

## 完了条件

1. 制作工程と判断理由を1案件分記録できる。
2. AIが初期タグを付けられる。
3. 類似案件を検索し、流用できる工程と差分を提示できる。
4. 最終データの文字・版・出力を独立して確認できる。
